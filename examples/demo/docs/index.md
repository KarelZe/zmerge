# zmerge example

This site merges the documentation of two projects with [zmerge](https://karelze.github.io/zmerge/). Both are built
from their GitHub repositories and share one navigation and one search.

- **[lev](lev/index.md)**: a fast Python library for the Levenshtein distance.
- **[datamodel-code-generator](datamodel/index.md)**: generates Python data models from OpenAPI, JSON Schema and more.
