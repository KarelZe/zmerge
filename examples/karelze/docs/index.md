# KarelZe's projects

This site merges the documentation of two projects with [zmerge](https://karelze.github.io/zmerge/). Both are built
from their GitHub repositories, share one navigation and one search, and links between them are validated.

<div class="grid cards" markdown>

- **[lev](lev/index.md)**

    An extremely fast Python library for the Levenshtein distance, written in Rust. See its
    [API reference](lev/api.md).

- **[dame](dame/index.md)**

    An extremely fast international draughts engine for Python, written in Rust. Learn about its
    [command line](dame/cli.md) and how its [opening book](dame/design.md#opening-book) works.

</div>
